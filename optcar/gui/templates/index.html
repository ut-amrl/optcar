Save the recorded body twist in a separate auxiliary bin, aligned with the main bin. Missing auxiliary data does not block conversion.

Default: 15 float32 columns, world pose and velocity, plus velocity/steering commands. Uses bag time and the latest sample at each timestep, matching WheeledLab raw alignment.
