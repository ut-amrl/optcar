# OptCar Project Website

Project page for **OptCar: Adapting Generalist Vehicle Models for High-Speed MPC Across Terrains**.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

The site is static and does not require a build step. The source paper figures are preserved as PDFs in
`assets/images`; PNG previews of the three displayed figures are included for consistent browser rendering.

## Structure

- `index.html` — page content and metadata
- `styles.css` — responsive layout and visual styling
- `assets/images/` — original manuscript figures and browser-ready previews
- `assets/videos/` — original experiment videos
- `assets/OptCar.pdf` — project paper
